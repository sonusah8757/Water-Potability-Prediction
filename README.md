# Water Potability Prediction
## Project Overview
This project predicts whether water is safe for drinking using Machine Learning techniques.

The model analyzes different water quality parameters such as:
- pH
- Hardness
- Solids
- Chloramines
- Sulfate
- Conductivity
- Organic Carbon
- Trihalomethanes
- Turbidity

and classifies water as:
- Potable (Safe)
- Not Potable (Unsafe)
